# SEO in Astro

Automatically generate `robots.txt`, `sitemap.xml`, `llms.txt`, JSON-LD structured data, and page metadata in your Astro
application.

## Getting started

Please follow the documentation
at [seo-in-astro.dlcastillop.com](https://seo-in-astro.dlcastillop.com/).
