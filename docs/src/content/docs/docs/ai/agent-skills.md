`seo-in-astro` comes with a list of Agent Skills that define best practices for working with this library.

These skills are useful for AI agents like Claude Code, Codex, or Cursor.

## Installation

```sh
npx skills add https://github.com/dlcastillop/seo-in-astro --skill seo-in-astro
```
